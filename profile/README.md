# coilyco-gaming

GitHub home for games, simulations, mods, and game-service tooling.

## Repositories

- [`coilyco-gaming/.github`](https://github.com/coilyco-gaming/.github)
- [`coilyco-gaming/eco-app`](https://github.com/coilyco-gaming/eco-app) - Eco MCP service - server, jobs, replay, telemetry.
- [`coilyco-gaming/eco-mods`](https://github.com/coilyco-gaming/eco-mods) - Eco mods and Unity assets.
- `coilyco-gaming/eco-ops` - 🔒 _(private repo)_ Eco operational inputs - cycle-prep, configs, private mods.
- `coilyco-gaming/factorio-mods` - 🔒 _(private repo)_ Factorio mods.
- `coilyco-gaming/factory-game-v3` - 🔒 _(private repo)_
- [`coilyco-gaming/galaxy-gen`](https://github.com/coilyco-gaming/galaxy-gen) - Procedural galaxy simulation - Rust compiled to WASM, rendered in the browser. Live at https://galaxy-gen.coilysiren.me
- `coilyco-gaming/sirens-discord-ops` - 🔒 _(private repo)_ Go ops tooling for the Sirens Eco community Discord: message dumps, normalization, and analysis pipelines.
- [`coilyco-gaming/steam-ops`](https://github.com/coilyco-gaming/steam-ops)
